--- BEGIN PROMPT ---

Design and implement the complete User Interface and interactive HUD architecture
for "ASTRA-1: The Red Frontier" (a 2026 NASA Space Apps Junior Astronaut Mission
Trainer set on Mars across a 10-mission / 378-Sol CHAPEA analog campaign,
targeted cleanly at Junior Astronauts aged 7-12 while offering an optional
Engineer Telemetry mode).

### 1. Visual Design System & Ergonomics
- **Aesthetic & Palette:** Deep-space sci-fi HUD over rich dark backgrounds
  (`#020617` / `bg-slate-950`), translucent layered glass panels (`.hud-panel`
  with subtle `border-sky-500/30` or `border-white/10`), high-contrast readable
  typography (`Orbitron` for `.font-display` headings, `Inter` for clean prose,
  `JetBrains Mono` / `.font-mono-tech` with `tabular-nums` for telemetry).
- **Zero-Clip Viewport Budget:** The root shell (`h-screen w-screen
  overflow-hidden flex flex-col`) keeps the HUD anchored cleanly along edges so
  the central 3D WebGL (`#three-container`) / 2D (`#game-canvas`) habitat
  remains unobstructed on both desktop and mobile screens.
- **Clutter Reduction & Two-Tier Disclosure (`Simplified UI` Default):**
  - Default `state.uiSimplified = true` keeps mission briefings and equipment
    modals concise and scannable for kids.
  - Provide live toggle buttons (`✨ Simplified UI` / `📜 Classic UI`) on both
    the Mission Briefing (`#btn-toggle-ui-mode`) and Equipment Console
    (`#btn-toggle-ui-mode-console`), plus collapsible secondary detail sections
    (`#btn-toggle-console-info` "💡 Science & Telemetry" and
    `#btn-story-science-more` "+ More").
- **Input & Accessibility Parity:**
  - Support keyboard (`WASD`/Arrows to move, `E` to interact with nearest
    object/NPC, `F` to operate outer airlock door, `Q` for quick hardware card,
    `ESC` to dismiss/abort active modals), mouse click-to-walk on the floor, and
    touchscreen controls (`.dpad-btn`, `#btn-touch-e`, `#btn-touch-f`).
  - Provide WCAG AA contrast, focus visibility, and unambiguous action buttons.

### 2. Primary HUD Layout Zones (Always Accessible In-Game)
1. **Top Telemetry Bar (`<header>`):**
   - **Left:** Sol & campaign badge (`#badge-hud-sol` displaying `SOL XX / 378`),
     mission tag (`#hud-chapter-tag`), and room subtitle (`#hud-location`).
   - **Center:** Immediate Focus Objective Pill (`#active-objective-pill`)
     showing a single-line `"TASK: <active objective>"` summary; clicking
     expands/focuses the Mission Checklist.
   - **Right Telemetry:**
     - **Cadet Mode (Default, `#hud-cadet-meters`):** 3 simplified color-coded
       safety pills (`Power`, `Life Support`, `Shield`). Clicking any pill makes
       ARIA explain what it measures in kid-friendly terms.
     - **Engineer Mode (Toggleable via `#btn-hud-mode`, `#hud-engineer-meters`):**
       5 raw readouts (`GEN/LOAD kW`, `BATTERY %`, `ATMO / CO₂` + live `#spark-co2`
       trend canvas, `WATER L | µS/cm`, `FOOD / RAD mSv/h`).
     - **3-Heart Life Display (`#hud-hearts-container`):** Crisp horizontal
       row of `❤️❤️❤️` indicating survival buffer before Mission Failed.
     - **Top-Bar Utility Actions:** Quick Door shortcut (`#btn-quick-door-f`),
       10s Dust Storm test (`#btn-quick-dilemma`), Live NASA DONKI Weather
       (`#btn-donki-weather`), HUD Mode switch (`#btn-hud-mode`), Power Breaker
       Grid (`#btn-power-grid`), Badges/Codex (`#btn-codex` showing `X/5`), and
       Settings Menu (`#btn-settings`).

2. **Center Playable Viewport (`<main>`):**
   - Renders `#three-container` (default Three.js 3D habitat & Mars terrain) or
     `#game-canvas` (2D fallback), keeping Cadet Nova smoothly centered.
   - Floating **Location Pill (`#hud-location-banner`)** dynamically updates to
     show the active room number and name.
   - Conditional **Emergency Alert Banner (`#emergency-banner`)** appears only
     when a live hazard fault (overload, high CO₂, leak, storm, flare) is active.
   - Floating **Proximity Prompt (`#interact-prompt`)** above bottom bar shows
     `[E]` or `[F]` keycap + object/door name when in range.
   - Dismissible **Hardware Spec Card (`#hud-prop-card`)** opens on `[Q]` with
     subsystem code, operational status, and summary.

3. **Collapsible Left Overlay — Mission Checklist (`#panel-checklist`):**

     10 chapters = 30 total tasks), Sol badge, active crisis countdown bar
     (`#task-timer-bar-container` during timed emergencies), and the green
     `Complete Chapter & Advance Sols` button (`#btn-advance-chapter`) once all

4. **Collapsible Right Overlay — Crew Status & Tools (`#panel-trainer`):**

   - Renders equipment schematic (`#console-illustration`), status pill, metrics

   - **Unified Airlock Animation Requirement:**
     - Both clicking/interacting with the `airlock_console` (`ch1_airlock`) AND
       approaching/activating the outer EVA hatch (`door_airlock_eva` via `openAirlockExitProcedure()`) MUST use the single unified **3-column Airlock Astronaut Chamber animation** (`renderM1T1_AirlockPressure` inside `#modal-console`):
